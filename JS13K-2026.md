# js13kGames 2026

Notes for taking Kindness TD to the competition. Source of truth is
<https://js13kgames.com/2026/rules> - this file is a working summary, not a
substitute.

## The theme: Unicorns and Rainbows

The theme is a scored rating criterion, but interpretation is left entirely to
the entrant. Kindness TD's hook into it is **HappyHorn the Unicorn**, a hero
unit who orbits the Grumpies leaving a rainbow trail behind them.

## Hard requirements

| Rule | Requirement | How we satisfy it |
| --- | --- | --- |
| Size | `.zip` archive of **13,312 bytes or less** (13 x 1024) | `npm run build` fails the build if `dist/kindness-td.zip` exceeds it |
| Archive layout | `index.html` in the archive's **top level**, playable straight after unzipping | The build emits a single-file `index.html` and validates the listing with `unzip -l` / `unzip -t` |
| No external resources | All code, assets and data inside the zip. No CDNs, no Google Fonts, no analytics | The build scans the output for `src`/`href` values pointing off-host and fails if it finds any |
| Browsers | Must work in latest Chrome **and** Firefox with **no console errors** | Verify both before submitting; see "Before submitting" below |
| Readable source | A GitHub repo with unmangled source and the build needed to produce the zip | This repo: `kindness-core.js`, `kindness-td.js`, `index.html`, `tools/` |
| New content | Must be a new game, not an old demo or a tutorial clone | Kindness TD is original work |
| Licensing | We must hold rights to every asset | Everything is hand-authored pixel art and canvas drawing; no third-party assets |
| localStorage | Namespace your keys, and never call `localStorage.clear()` - games share one origin | The game currently uses no storage at all. If we add saves, prefix keys with `ktd:` |
| Tech | Anything that runs in a browser or compiles to it. No plugins or extensions | Plain JS, Canvas 2D, no dependencies at runtime |

## Categories

- **Desktop** and **Mobile** are the two base categories and are covered by the
  rules above. Kindness TD already supports pointer and touch input, so it can
  target either.
- **Online** and **WebXR** carry extra rules we are not opting into.

## Building

```bash
npm ci
npm run build
```

The build concatenates the source files, minifies them with Terser, inlines the
result into a minified `index.html`, and writes `dist/kindness-td.zip`. It then
prints the byte count against the budget and exits non-zero if we are over.

`advzip` (from `advancecomp`) is optional. If it is on PATH the build uses it to
recompress the archive, which typically buys a few hundred extra bytes:

```bash
brew install advancecomp
```

### Compression choices

Terser runs without `unsafe*`, `booleans_as_integers` or `pure_getters`. Those
were measured at 67 bytes on this codebase, which is a poor trade for transforms
that can reorder float math or change truthiness in a game judged partly on
running without errors.

### Debug build

```bash
node tools/build.mjs --debug
```

Applies the same compression but skips name mangling and writes
`dist/debug.html` next to the package, so the compressed output can be poked at
in the browser. Also handy for confirming that a behaviour check that passes
against the readable source still passes after minification.

### Local server

```bash
npm run serve
```

Serves the repo root on <http://localhost:8013>: `/` is the readable source and
`/dist/index.html` is the built package.

## The hero: HappyHorn the Unicorn

The theme hook is a hero unit in the build menu at 120 Kindness, capped at one
per game. Unlike the other towers she does not sit on her cell: she flies a
squashed loop around the nearest sad grumpy within 300px of her cell and drops a
rainbow segment every 30ms behind her.

Two things cheer grumpies up, and a grumpy can only benefit from one of them per
frame:

- the grumpy she is circling, tended to directly at 22 sad/second
- any other grumpy the rainbow trail touches, at the same rate

She is tended-to-directly rather than trail-only because she orbits at 34px
while the trail's touch radius is 16px, so the grumpy she circles sits in the
hole in the middle of her own ring and the rainbow would otherwise sweep around
them instead of over them.

## Before submitting

1. `npm run build` - confirm the archive is under budget.
2. Unzip `dist/kindness-td.zip` somewhere clean and open `index.html` directly.
   It must be playable with no console errors.
3. Repeat the check in both Chrome and Firefox.
4. Play a full round on a touch device or with device emulation.
5. Submit the zip as the *playable* source and this repo as the *readable* one.
